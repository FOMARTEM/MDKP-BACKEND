## Примечания

- **Авторизованный** — пользователь с любым действующим JWT токеном
- **Администратор** — пользователь с ролью `admin`
- **Автор** — пользователь, создавший задачу (для удаления задачи)
- **Пагинация**: `limit` (по умолчанию 32), `offset` (по умолчанию 0)
- **Форматы дат**: `YYYY-MM-DD` для фильтрации, `RFC3339` для вывода
- **JWT токен** передается в заголовке: `Authorization: Bearer <token>`
