# Задачи по доработке логики

Пользователи:
    1) Установить дату смены пароля (новое поле в БД), особенно для временнго пароля

Задачи:
    1) Сделать так что бы удалить задачу можно было только когда у неё нету версий, для материалов каскадное удаление
    2) Продумать логику согласования задачи и отправки их редактору
    3) Отображать только задачи пользователя ++
    4) Добавить возмонжость филтрации задач
    5) Реализовать пагинацию

Версии:
    1) Сделать так что бы нельзя было просто выбрать статус задачи (присвоить им статкиик по кнопкам)
    2) Добавить возможность добавлять материал для версии
    3) Убрать возможность добавляться материалы редакторам и авторам для задачи
    4) Добавить возможность фильтрации версий
    5) пагинация

Правки:
    1) Доработать логику с состоянием
    2) пагинация
    3) логика архивности

Материал:
    1) Добавить возможность поиска

Логи:
    1) Добавить логирование к действиям пользователей
    2) Улучшенная пагинация

Статистика:
    1) Получение статистических данных определённого пользователя
    2) Статистика подчинённых
    3) Личная статистика
